How this worksheet works

  • This worksheet is a tutor. It takes about about 75 minutes. Do it in parts. The time for each part is at the top of the part.
  • Each part starts with a short lesson and a worked example. Read it, then try the questions.
  • Every question has a cheat sheet, up to three hints, and a worked answer that appears after you check.
  • Press Check as often as you like. A ✓ means correct. A ✗ means not yet. Read the message beside a ✗.
  • If you get a question wrong, a new box opens under it: Let’s look at this a different way. It asks a smaller question that finds the mistake. Answer it, then go back to the first question.
  • If you get a question right, a Stretch question may open. It is harder and it is there to deepen your understanding.
  • More practice gives you a new question of the same kind. Use it until you can get full marks first time without a hint.
  • The Mastery check at the end shows whether you have reached Mastery. If not, you are Working towards Mastery: it names the part to go back to. Your best mark is kept, so you can try again.
  • Write answers to calculations as numbers. The unit is shown beside the box. Type formulae on one line, for example Ca(OH)2.
  • The Reference sheet button (top right) opens the tables you need. Move the pointer over a dotted word to see what it means. The glossary is at the end.
  • Save progress keeps your answers in a file. Retrieve progress brings them back. Save as a .pdf file opens the print window: choose Save as PDF as the printer.
